01 / SYSTEM MAP

Offline Research 全链路与 MVP1 边界

完整系统有六条研究产品线；MVP1 不试图一次完成所有内容，而是先打通“公共测量 + 三类对象研究 + 两道 Gate + 运行回放”。

02 / PUBLIC CHAIN

为什么要有公共链，以及它怎样生成

公共链不是对象主流程前面的一条“大流水线”，而是 Trait / State / Signal 在需要数据能力时调用的共享实验室。

人工预设代码执行LLM 辅助人工验证
避免三条线重复造数据逻辑

PIT、来源绑定、单位、测量、充分性只实现一次。

避免共享无边界“大宽表”

每次调用必须带 StudySpec、用途、字段 allowlist 和 as_of。

隔离分支上下文

共享原始事实和背景，但默认看不到其他分支的最终 Assessment。

让证据可以回放

每个返回包包含版本、hash、known_at、来源与异常原因。

对象节点调用共享实验室，而不是把结论外包

TR02.T02 / T03 → ObjectDataRequest

研究用途、as_of、最小字段、允许来源、禁止读取的分支结果。

F01–F06 只生产通用事实 / 机会 / 测量 / 充分性 / Context
ResearchInputBundle → TR02.T02 / T03

T02 再解释为 EligibleEpisodes；T03 再解释为 TR02 IndicatorBook。公共链不输出“TR02=True”。

F01

Source Binding

人工冻结来源语义；代码绑定 subject、grain、unit、effective/known time。

F02

PIT Snapshot

代码只保留 as_of 当时已知记录，保留迟到修订与 supersedes 血缘。

F03

Opportunity Book

人工定义 opportunity；代码枚举完整候选分母与不可观察原因。

F04

Measurement

人工批准公式/单位/方向；代码生成分子、分母、coverage 与 missing reason。

F05

Adequacy

人工预注册门槛；代码检查历史、覆盖、方法家族、split 与独立参照。

F06

Context Packet

人工批准 allow/deny policy；代码强制每个 worker 能看什么、不能看什么。

TR02 具体例子： BAL-v1 known_at=10/01 可以进入 10/01 快照；BAL-v2 known_at=10/05 不能回填。F03 产生 9 条候选机会，F04 产生 stable cash share / buffer ratio / rollover persistence，F05 因独立构念参照缺失返回 DEFER，最终交回无对象结论的 Bundle。
03 / RESEARCH MODULES

每条产品线逐节点：谁预设、谁执行、谁验证

点击下面任一步骤可展开 Input、Output、人工预设、LLM 辅助、Human Validation 与具体例子。

不是每一步都人工点批准

每一步都必须可追溯、可展开、可复现；但正常计算节点自动执行。人工集中在研究设计、异常/近门槛案例和最终发布决策。

Gate A · 研究设计审核检查 T01/T02、指标、rivals、validation protocol。
T03–T08 · 自动执行代码按冻结配置运行；失败、数据不足、近门槛才创建 ReviewTask。
Gate B · 结果与发布审核查看 Validation Report，approve / defer / reject / redefine。

06 / DELIVERY ROADMAP

从 0 到 1 的建议落地顺序

先把一条链路跑真，再增加对象；避免一开始把 37 个槽位、复杂 Agent 和完整平台同时建设。

1

冻结合同与边界

  • Object / Source / Measurement
  • NodeSpec 与 ContextPolicy
  • Gate A/B 模板
2

做实 TR02 切片

  • 公共链 F01–F06
  • T01–T10 RunManifest
  • 可复现 Validation Report
3

验证三分支通用性

  • 加入 ST01 与 SG01
  • 同快照、上下文隔离
  • 一支失败不影响其他支
4

形成迭代闭环

  • Review / Bad Case
  • Config / Prompt Eval
  • 日批、监控、版本回退

管理层需要批准的不是 30 个节点，而是三件事

研究边界是否合理、证据是否足够、用途与风险是否允许发布。
